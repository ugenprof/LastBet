# Последняя ставка — Unity-версия

Нарративная игра с выборами и мини-играми: подросток втягивается в азартные игры. Порт браузерной версии
(`C:\AI\unity1`) на Unity: сюжет, правила, баланс и концовки те же, графика новая (вся рисуется кодом).

## Как открыть и запустить

1. Установите **Unity Hub** (https://unity.com/download) и через него **Unity 6** (проверено на **6000.6.7f1**, «Unity 6.6»).
   При установке отметьте модуль **Windows Build Support (Mono)** (обычно стоит по умолчанию).
2. Unity Hub → **Add** → **Add project from disk** → выберите папку `C:\AI\LastBet`.
   Если Hub спросит версию редактора — выберите установленную Unity 6.
3. Первое открытие идёт несколько минут: Unity импортирует проект, 3D-модели и пакеты (uGUI, Newtonsoft JSON).
   Скрипт `Assets/Scripts/Editor/ProjectSetup.cs` сам создаст сцену `Assets/Scenes/Main.unity`,
   добавит её в сборку и задаст название игры. Если Unity предложит обновить проект или API — соглашайтесь.
4. Нажмите **▶ Play** вверху редактора — игра запустится в окне Game. Окно Game удобнее развернуть:
   в его заголовке выберите соотношение **16:9** (или Full HD 1920×1080) — интерфейс рассчитан на широкий экран.

Если в консоли (Window → General → Console) есть красные ошибки, пришлите их текст целиком.

## Сборка .exe

Меню **Последняя ставка → Собрать для Windows (.exe)** → выберите папку. Получится `LastBet.exe` и рядом
папка `LastBet_Data` — для запуска на другом компьютере нужна вся папка целиком.

Без открытия редактора (закройте его, если проект открыт) — сборка в папку `Build`:

```
"C:\Program Files\Unity\Hub\Editor\6000.6.7f1\Editor\Unity.exe" -batchmode -projectPath C:\AI\LastBet -executeMethod ProjectSetup.BuildWindowsBatch -logFile build.log
```

После правок кода или моделей игру нужно собрать заново — готовый `.exe` их не подхватит.

## Управление

- Мышь: кнопки выбора, карточки команд, товары на прилавке.
- Клавиши **1–9** — выбор кнопки по номеру, **Esc** — закрыть окно, **F11** — полный экран.
- Игра сохраняется каждое утро; при следующем запуске можно продолжить с утра того дня.
  Удалить сохранение: меню **Последняя ставка → Удалить сохранение** (в редакторе) или «Начать новую игру» при запуске.

## Устройство проекта

Всё строится кодом — сцена пустая, префабов нет. Точка входа — `Assets/Scripts/Boot.cs`.

| Папка | Что там |
|---|---|
| `Assets/Resources/Data/` | Данные: `story.json` (264 сцены), `texts.json` (строки интерфейса), `catalog.json` (вещи, команды, меню…), `characters.json` (внешность), `texts_unity.json` и `passers.json` — то, чего не было в браузерной версии |
| `Assets/Scripts/Config/Balance.cs` | Все числа баланса (класс `B`) — сгенерирован из `balance.js` |
| `Assets/Scripts/Core/` | Модели, загрузка данных, состояние (`GameState`), шаблоны текста, таймеры, сохранение |
| `Assets/Scripts/Engine/` | `Game.Render` и реестры (`Routes`, `Screens`, `Texts`, `Builders`), правила, эффекты выборов, фильтры кнопок |
| `Assets/Scripts/Scenes/` | Логика особых сцен — те же файлы и функции, что в `js/scenes/` |
| `Assets/Scripts/Games/` | Казино (рулетка, матчи, слоты, ракета) и подработки |
| `Assets/Scripts/UI/` | Интерфейс (uGUI): раскладка, HUD, окна, кнопки, персонажи на сцене |
| `Assets/Scripts/Art/` | Графика кодом: растеризатор `Painter`, фоны, персонажи, значки |
| `Assets/Scripts/Audio/` | Музыка с плавной сменой по зонам |
| `Assets/Resources/Music/` | Треки Kevin MacLeod (CC BY 4.0) — авторы в `CREDITS.txt` |

Код повторяет браузерную версию почти один в один: `render()` → `Game.Render()`, `SCENE_ROUTES` → `Game.Routes`,
`state` → `G.S`, константы `balance.js` → `B.*`. Так правку из одной версии легко перенести в другую.

## Как менять сюжет

Сюжет по-прежнему пишется в браузерной версии (`js/story/*.js`, `js/config/*.js`), потом выгружается в Unity:

```
node Tools/export_story.js C:\AI\unity1
```

Скрипт перезапишет `Assets/Resources/Data/{story,texts,catalog,characters}.json` и `Assets/Scripts/Config/Balance.cs`.
Новое число баланса появится в `B` само; новую логику (сцену с особым поведением) нужно дописать в C#.

## 3D-персонажи

Персонажи на сцене — 3D-модели (стиль «игрушечная диорама»), фоны и мини-игры — 2D, как раньше.
Модели строит кодом Blender-генератор `Tools/Blender/` и кладёт в `Assets/Resources/Models/Characters/ch_<имя>.fbx`.
В игре каждому персонажу на сцене даётся своя камера, она рендерит модель в текстуру, а интерфейс показывает её на месте
2D-портрета (`Assets/Scripts/UI/Actor3D.cs`). Эмоции переданы позой: радость — пружинит, грусть — никнет и отворачивается,
злость — подаётся к собеседнику; говорящий кивает.
На экране выбора героя — по три варианта внешности для мальчика и девочки (стрелки «‹ ›»);
варианты описаны в `Assets/Resources/Data/heroes.json` (первый — из `characters.json`).
В рюкзаке купленное можно надеть: футболку или худи, шорты, кроссовки, наушники, часы, смартфон в руке —
слева примерка в полный рост, надетое видно на герое во всех сценах. Прохожие в раздаче листовок — тоже 3D,
в полный рост и с реквизитом (велосипед, самокат, коляска, трость, наушники).

- Материалы настраиваются при импорте по имени материала (`Assets/Scripts/Editor/ModelImport.cs`) — руками не нужно.
- Проверить модели в Unity: меню **Последняя ставка → Снимок 3D-персонажей** → картинка `Docs/unity_characters.png`.
- Вернуть 2D-персонажей: удалить (или вынести из `Assets`) папку `Assets/Resources/Models` — игра сама перейдёт на 2D.
- Пересобрать модели после правки `characters.json` или генератора (Blender 4.0+, проверено на 5.2):
  `blender --background --factory-startup --python Tools/Blender/build_models.py`

## Графика

Ни одной картинки из браузерной версии: фоны (22 места), 30 персонажей с эмоциями, морганием и речью,
колесо рулетки, символы слотов, ракета, вещи, товары и значки рисуются кодом при запуске (`Assets/Scripts/Art/`).
Эмодзи из текстов шрифт Unity не рисует, поэтому они убираются из строк (`Txt.Clean`), а в мини-играх
вместо них нарисованные значки.
